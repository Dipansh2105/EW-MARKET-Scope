# EVMarketScope ⚡
### Electric Vehicle Market Intelligence Website

EVMarketScope is a static website presenting an EV market analytics project. It highlights regional annual sales, manufacturer performance, battery technology distribution, and customer ratings.

## Features
- Responsive landing page (desktop + mobile)
- Project overview and feature cards
- Dashboard screenshot preview and link to dashboard PDF
- Methodology/workflow section
- GitHub Pages compatible (no build tools required)

## Tech stack
- HTML5
- CSS3
- Static assets (PNG + PDF)

## Run locally
Open `index.html` in your browser.

## Publish using GitHub Pages
1. Create a new GitHub repository (e.g. `EVMarketScope`).
2. Upload **all files and folders** from this project. `index.html` must be in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes. GitHub will show the published website URL in the Pages section.
